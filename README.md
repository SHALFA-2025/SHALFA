# SHALFA (شَلْفَا) – Unmanned Surface Vehicle Prototype

Bilingual (Arabic / English) project website with a real-time 3D model of the boat.
Static site: publish with GitHub Pages. No build step.

Project started and created in 2025.

## Enable the contact form

The quick-contact form at the bottom sends through FormSubmit (free, no account).

1. Open `index.html` and find the line `var CONTACT_TO='';`
2. Put the inbox that should receive the messages between the quotes, e.g. `var CONTACT_TO='name@gmail.com';`
3. Publish the site, open it, and send one test message. FormSubmit emails you an activation link the first time; click it once.
4. After activation FormSubmit shows a private alias (a random string). You can put that alias in `CONTACT_TO` instead of your email so your address is not visible in the page source.

Visitors only get through if the name, email and message are filled in and the email is from a trusted provider (Gmail, iCloud, Outlook, Hotmail, Yahoo, Proton and similar). Each sender also receives a copy of their message.
